# InsightFlow AI

A modular React application scaffolded from a single-file Claude Artifacts app. Built with Vite and React.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Build production assets:
   ```bash
   npm run build
   ```

## Presentation notes

- The analytics dashboard now includes clearer vertical axis labels, visible gridlines, and a more compact layout that remains readable on smaller screens.

Open the component in your editor, trigger the suggestion, and capture the inline recommendation in the editor pane for your report.
